# 首次使用引导

新环境打开应用后，引导会帮助完成连接、本机授权、模型配置、论文上传、索引和第一次问答。
后端无法连接、本机尚未授权或知识库为空时，会自动展开。已有可用文献的用户默认进入原页面。
点击“关闭引导”可以继续使用；点击“首次使用引导”可随时重新打开。

1. **检查连接。** Docker 部署先启动 Docker Desktop / Docker Engine，然后在项目目录执行
   `docker compose up --build`。不能连接时按[环境诊断](environment-diagnostics.md)检查端口和依赖。
   后端恢复后，点击“刷新引导状态”。后端在线不代表数据库、Redis、worker 或模型已就绪。
2. **完成本机授权。** “前往本机授权”打开现有配对页面。桌面凭据保存在系统凭据库，
   按页面提示完成后端配对；Web 使用现有开发授权流程，凭据不保存在浏览器存储中。
   具体部署与配对步骤见[部署说明](deployment.md)。
3. **检查模型配置。** “检查模型设置”打开 Settings，配置四个聊天角色和运行时凭据。
   没有 API Key 仍可以检查环境，但不能据此认为远程模型能够推理。
   连接测试是可选操作，需手动点击，可能产生费用；引导不会自动执行测试。
4. **上传论文。** “上传第一篇论文”打开现有 Knowledge Base。选择 PDF 并上传。
   解析、Embedding 或首次模型下载可能较慢，远程 Embedding 也可能收费。
   若诊断显示依赖缺失，先按提示修复依赖。
5. **等待索引。** 上传被接受不代表索引完成；等待列表显示 indexed 和来源片段。
   引导展开且后端在线时，每 5 秒读取一次状态，也可手动刷新。
   可用文献必须 indexed、有 chunk 且未标记为撤回/撤稿；计数不证明检索质量。
6. **首次问答。** 文献、聊天配置和问答/索引基础服务可用，且已知必要依赖未缺失时，
   “打开首次问答”会打开原 RAG 页面。输入问题并点击发送；远程模型调用可能收费。
   模型配置存在不保证真实调用成功，答案仍需核对论文原文和引用。

“本机诊断与版本”复用现有诊断页面，分别显示基础设施、队列、知识库与尚未验证的模型状态。
状态无法读取时，会给出重新检查、本机授权或修复服务的下一步操作。

关闭引导只记住界面偏好，不清除文献、会话、索引或记忆。应用重启后读取原有服务器数据；
若浏览器禁止本地存储，关闭偏好只对当前窗口有效，仍可关闭或重新打开。
引导不会安装环境、修改授权配置、代填密钥或重置数据库；最终安装方案另行验收。

Playwright 使用明确标记的 MOCK HTTP/SSE 数据验证流程和 UI 数据保留约定。
这些测试不是实际 PDF 解析、付费推理、科研质量或人工 Windows 11 安装验收。
