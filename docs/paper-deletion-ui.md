# 文献删除与历史来源显示

Knowledge Base 每行提供“删除文献”。第一次点击只读取当前元数据和删除范围；
确认窗核对两次读取的版本、展示受影响文本块/证据/未完成导入，并说明独立副本。
勾选明确确认后才发送 TASK-06 的 DELETE；取消或 Escape 在提交前不产生写入。
提交期间禁止重复操作和取消；请求中断并不代表后端回滚。
元数据冲突后必须重新读取预览、重新勾选确认，不自动接受另一版本。

删除记录确认 `library_removed=true` 后立即从列表排除文献并刷新当前分页。
“已移出当前知识库”与“受管文件清理完成”分别显示；queued/running 的状态在
可见页面每五秒读取，返回窗口或恢复网络时也核对。失败/中断清理和未派发 queued
状态只提供显式 POST 重试，Run ID 由服务器返回。读请求十秒、提交三十秒超时；
失联时先 GET 删除账本，状态未知时禁止重放 DELETE 或自动重试清理。
读状态服务失败时保留已经确认的移除事实，并给出安全诊断指导。

浏览器在存储可用时仅保存最近二十个 UUID 文献 ID，用于重载后的只读查询；
不保存标题、原文、凭据、确认请求或持久化任务队列。关闭提示只移除本地提示记录，
不取消或恢复服务器操作。浏览器清理存储、禁止存储、换客户端或超过二十条时，
不会自动恢复所有提示；后端删除账本仍保留，可用文献 ID 查询状态。

所有预览/状态显示明确保留副本：桌面 documents 缓存、外部阅读器、下载/另存文件、
备份/同步、服务商留存，以及历史回答/问题/摘要正文。共享或未受管文件的保留原因
也单独展示。不删除这些副本，不将“受管清理完成”表述为所有副本已抹除。

历史消息的根级/compact presentation/Run 来源失效标记会显示“历史回答 · 来源不可用，
当前不可验证”，保留真实历史执行状态和回答正文。已删除引用显示非交互的失效标记；
不展示其原文/PDF，不影响另一来源的引用。消息 updated_at 变化会撤销在途旧详情、
废弃缓存和旧执行事件，并关闭该消息的旧引用窗口。每次打开引用都重读该 Run，
因此已缓存来源在另一窗口删除后也不会直接沿用旧原文。返回窗口只更新最多五十个
已显示的引用消息；不会周期性扫描整个历史或预下载全部 Run。

桌面仅新增 UUID Paper DELETE、两个 GET 预览/状态和固定 POST 清理重试路由。
仍禁止错误方法、非 UUID、路径编码、穿越和任意查询/目的地址；IPC 确认体保留
版本/范围/显式确认，授权继续由 native 层持有。

Playwright 使用明确 MOCK HTTP 状态验证确认、取消、冲突、失联、失败重试、其他文献/
会话保留和历史失效/迟到响应。真实检索排除、DB 回滚、文件/RQ 隔离由已验收的
TASK-06 实际 PostgreSQL/Redis 测试证明；浏览器 fixture 不代表模型科研效果。
本任务没有付费推理、模型下载、后端/迁移/锁文件改动。Rust 编译/测试/Clippy 和
Windows 安装包/Linux 原生 GUI 由实际 GitHub Desktop CI 验证，不能替代 Win11 人工验收。
